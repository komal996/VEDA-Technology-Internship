# Task 27 – Java Multithreaded Number Processor

##  Project Overview
The Multithreaded Number Processor is a Java application that demonstrates multithreading by processing numbers using multiple threads. It helps understand concurrent execution and the basics of Java thread management.

## Objectives
- Understand Java multithreading.
- Create and execute multiple threads.
- Perform number-processing operations concurrently.
- Learn thread execution and synchronization basics.

## Technologies Used
- **Programming Language:** Java
- **Concepts:** Multithreading, Threads, Runnable, Concurrency
- **Tools:** VS Code / Notepad, Command Prompt or PowerShell, Git, GitHub

##  How to Run

1. Open PowerShell in the project folder.
2. Compile the Java program:

   ```powershell
   javac -d . MultithreadedNumberProcessor.java
   ```

3. Run the program:

   ```powershell
   java -cp . MultithreadedNumberProcessor
   ```
