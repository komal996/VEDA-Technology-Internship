# Task 6: Build a Palindrome Checker

## Internship

This project is developed as part of the **VEDA Technology Java Programming Internship**.

## Project Overview

The Palindrome Checker is a Java console-based application that checks whether a given **string or number reads the same forward and backward**.

For example:

- `Madam` → Palindrome
- `121` → Palindrome
- `Hello` → Not a Palindrome
- `123` → Not a Palindrome

## Objectives

The main objectives of this task are:

- To understand Java Strings
- To practice loops and conditional statements
- To compare characters in a string
- To understand number reversal
- To create and use methods in Java
- To work with user input using Scanner

## Features

- Check whether a string is a palindrome
- Check whether a number is a palindrome
- Case-insensitive string checking
- Simple menu-based interface
- User input using Scanner
- Separate methods for string and number checking
- Displays clear results to the user

## Technologies Used

- **Programming Language:** Java
- **Input:** Scanner
- **Concepts:** Strings, Methods, Loops, Conditions, Character Comparison

Java Concepts Used

1. Scanner

Used to accept input from the user.

2. Methods

Two separate methods are created:

isStringPalindrome()

and

isNumberPalindrome()
3. Loops

A while loop is used to compare string characters and reverse numbers.

4. Conditional Statements

if-else statements are used to determine whether the input is a palindrome.

5. String Manipulation

The toLowerCase() method is used for case-insensitive string comparison.
