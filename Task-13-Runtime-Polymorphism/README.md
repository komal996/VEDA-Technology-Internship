# Task 13: Runtime Polymorphism in Java

## VEDA Technology – Java Development Internship

### Project Overview
This project demonstrates **Runtime Polymorphism in Java** using method overriding and inheritance. It explains how different subclasses can provide their own implementation of a method defined in a parent class.

### Objective
- Understand runtime polymorphism in Java.
- Implement inheritance and method overriding.
- Demonstrate dynamic method dispatch.
- Improve object-oriented programming skills.
