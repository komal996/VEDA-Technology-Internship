# Task 16 – Library Management System

## VEDA Technology Internship | Java Programming

### Project Overview

The Library Management System is a console-based Java application designed to manage library operations efficiently. It allows users to manage books, register members, issue books, return books, and track overdue books.

This project demonstrates Object-Oriented Programming (OOP) concepts and the Java Collections Framework.

## Objective

To develop a Library Management System using Java that applies OOP principles to a real-world application.

## Technologies Used

- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Collections:** ArrayList, HashMap
- **IDE:** Visual Studio Code
- **Interface:** Console-based

## Features

### 1. Book Management
- Add new books to the library.
- Display available books.
- Search books using book IDs.
- Track book availability.

### 2. Member Management
- Register new library members.
- Store member details.
- Display registered members.

### 3. Book Issue System
- Issue books to registered members.
- Check book availability before issuing.
- Record the issue date and due date.

### 4. Book Return System
- Return issued books.
- Update book availability.
- Calculate overdue days.

### 5. Overdue Tracking
- Identify overdue books.
- Calculate the number of overdue days.
- Display overdue information.

## OOP Concepts Used

- **Classes and Objects:** Book, Member, and Library classes.
- **Encapsulation:** Manage data using private variables and methods.
- **Abstraction:** Organize library operations into methods.
- **Collections:** Store and manage books and members dynamically.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Compile the Java program:

```bash
javac -d . LibraryManagementSystem.java
```

4. Run the program:

```bash
java -cp . LibraryManagementSystem
```
