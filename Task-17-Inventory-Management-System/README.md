# Task 17 – Inventory Management System

## VEDA Technology Internship – Java Development

### Project Overview

The Inventory Management System is a console-based Java application developed as part of Task 17 of the VEDA Technology Java Development Internship.

This project helps manage product inventory by allowing users to add, view, search, update, and delete product records through a menu-driven interface.

### Objectives

- Understand Java Object-Oriented Programming (OOP).
- Implement classes, objects, and methods.
- Use ArrayList to manage product records.
- Apply loops and conditional statements.
- Develop a menu-driven console application.

### Features

1. **Add Product:** Add new products with their details.
2. **View Products:** Display available inventory records.
3. **Search Product:** Find a product using its ID.
4. **Update Product:** Modify existing product information.
5. **Delete Product:** Remove a product from inventory.
6. **Exit:** Close the application.
