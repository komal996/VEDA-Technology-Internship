# Task 18 – HashMap-Based Employee Lookup System

## VEDA Technology Java Development Internship

### Project Overview
This project is a console-based Employee Lookup System developed using Java and HashMap. It allows users to efficiently manage employee records using unique employee IDs.

The application demonstrates the practical implementation of Java Collections Framework, object-oriented programming, and key-value data storage.

## Objectives
- Understand the HashMap collection in Java.
- Store employee records using unique employee IDs.
- Implement fast employee searching.
- Perform employee insertion, updating, and deletion.
- Apply object-oriented programming concepts.

## Technologies Used
- **Programming Language:** Java
- **Collection Framework:** HashMap
- **IDE:** Visual Studio Code
- **Interface:** Console-based application

## Features
1. **Add Employee:** Add a new employee with ID, name, department, and salary.
2. **Search Employee:** Find an employee using their unique ID.
3. **Update Employee:** Modify existing employee details.
4. **Delete Employee:** Remove an employee record.
5. **Display Employees:** View all available employee records.
6. **Exit:** Close the application.
