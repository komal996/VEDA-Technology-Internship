# Task 5 – Multiplication Table Generator

##  Project Overview

The **Multiplication Table Generator** is a Java-based console application developed as part of **Task 5 of the Java Programming Track at VEDA Technology**.

The program allows the user to enter a number and generates its multiplication table. It can also be used to generate multiplication tables for a range of numbers.

This project was created to practice **loops, nested loops, methods, user input, arithmetic operations, and formatted console output** in Java.

---

## Task Objective

The main objective of this task is to:

- Practice Java loops
- Understand nested loops
- Generate multiplication tables
- Work with user input
- Practice methods in Java
- Display properly formatted console output
- Improve basic problem-solving skills

---

##  Task Description

Build a Java program that generates multiplication tables for a **user-provided number** and optionally generates tables for a **range of numbers**.

The program should provide clear and readable output in the console.
