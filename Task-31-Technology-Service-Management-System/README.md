# Task 31 – Technology Service Management System

## Project Overview
The Technology Service Management System is a Java-based application designed to manage the operations of a technology and digital-services organization such as Veda Technology.

It provides features to manage services, training programs, internship programs, customers, customer inquiries, and service requests.

## Objectives
- Apply Object-Oriented Programming concepts in Java.
- Understand inheritance and encapsulation.
- Work with ArrayList and HashMap collections.
- Implement exception handling.
- Develop a menu-driven management application.
- Generate basic organizational reports.

## Technologies Used
- Java
- JDK 8 or above
- IntelliJ IDEA / Eclipse / VS Code
- Git
- GitHub

## Features
1. Add and display technology services.
2. Register and display customers.
3. Add training programs.
4. Add internship programs.
5. Submit and display customer inquiries.
6. Create and display service requests.
7. Search services by name or category.
8. Update inquiry status.
9. Generate organizational reports.
10. Preloaded sample data for testing.

## Java Concepts Used
- Classes and Objects
- Inheritance
- Abstraction
- Encapsulation
- ArrayList
- HashMap
- Exception Handling
- Loops and Conditional Statements
- Methods and Modular Programming
