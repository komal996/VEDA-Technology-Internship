# Task 8 – ATM Simulation

## Project Overview

This project is a simple **ATM Simulation System** developed using **Java** as part of my Java internship at **VEDA Technology**.

The application simulates basic ATM operations such as PIN authentication, checking account balance, depositing money, and withdrawing money.

## Objectives

- Implement a simple ATM system using Java.
- Provide secure PIN authentication.
- Allow users to check their account balance.
- Allow users to deposit money.
- Allow users to withdraw money.
- Prevent withdrawals when the balance is insufficient.
- Handle invalid transactions properly.

## Features

- 🔐 PIN Authentication
- 🔢 Maximum 3 incorrect PIN attempts
- 💰 Check Account Balance
- 💵 Deposit Money
- 💸 Withdraw Money
- ⚠️ Insufficient Balance Handling
- ❌ Invalid Input Handling
- 🚪 Exit ATM System
- 🔒 Encapsulation using a `BankAccount` class

  💡 Program Logic

The application follows this basic flow:

 Start
  ↓
Enter PIN
  ↓
Verify PIN
  ↓
Correct PIN?
  ├── No → Retry
  │         ↓
  │     3 Attempts?
  │         ↓
  │       Lock
  │
  └── Yes
       ↓
   Display ATM Menu
       ↓
   Select Operation
       ↓
 ┌───────────────┐
 │ Check Balance │
 │ Deposit Money │
 │ Withdraw Money│
 │ Exit          │
 └───────────────┘
       ↓
   Continue Menu
       ↓
      Exit

## Technologies Used

- **Programming Language:** Java
- **Concepts:** OOP, Classes, Objects, Encapsulation
- **Input:** Java Scanner
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
