# Task 11 – Employee Management System Using OOP

## VEDA Technology – Java Programming Internship

### Project Description
This project is a console-based Employee Management System developed using Java and Object-Oriented Programming (OOP) concepts.

### Objective
To implement classes, objects, constructors, encapsulation, and methods in a practical employee management application.

### Technologies Used
- Java
- VS Code
- Object-Oriented Programming (OOP)

### Features
1. Add new employees
2. Search employees by unique ID
3. Update employee information
4. Display all employee records
5. Prevent duplicate employee IDs
6. Handle invalid user input

### OOP Concepts Used
- **Class and Object:** Employee class represents employee information.
- **Constructor:** Initializes employee details.
- **Encapsulation:** Employee data is stored in private variables.
- **Methods:** Perform employee creation, searching, updating, and listing.

### How to Run
Compile the program:

`javac EmployeeManagementSystem.java`

Run the program:

`java -cp . EmployeeManagementSystem`

### Learning Outcomes
Through this task, I improved my understanding of Java OOP concepts, constructors, encapsulation, ArrayList, and employee record management.
