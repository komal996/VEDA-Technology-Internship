# Task 9: Banking Account Class

## Description

A simple banking account application developed using Java to demonstrate basic banking operations.

## Features

* Create a bank account.
* Display account details.
* Deposit money.
* Withdraw money.
* Check the current balance.
* Validate transactions.
* Prevent withdrawals exceeding the available balance.

## Technologies Used

* Java
* Visual Studio Code

## Concepts Learned

* Classes and Objects
* Constructors
* Encapsulation
* Methods
* Conditional Statements

## How to Run

Compile:

```bash
javac -d . BankAccount.java
```

Run:

```bash
java -cp . BankAccount
```
