# Task 1 – Command-Line Calculator

This project is a simple **Command-Line Calculator** developed using **Java** as part of my **VEDA Technology Internship – Task 1**.

## Features
- Addition, Subtraction, Multiplication
- Division and Modulus
- User input using Scanner
- Separate methods for operations
- Invalid input handling
- Division-by-zero and modulus-by-zero handling

## Technologies Used
- Java
- JDK
- Scanner
- Switch-case
- Exception Handling

## How to Run

```bash
javac Calculator.java
java Calculator
