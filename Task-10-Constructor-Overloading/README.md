# Task 10: Constructor Overloading

## Objective
To understand constructors and constructor overloading in Java.

## Description
This program demonstrates multiple constructors in a Student class. Objects are initialized using different sets of information.

## Features
- Default constructor
- Parameterized constructor with two parameters
- Parameterized constructor with three parameters
- Displays student details

## Technologies Used
- Java
- Visual Studio Code

## Concepts Learned
- Classes and objects
- Constructors
- Constructor overloading
- The `this` keyword
- Methods

## How to Run
1. Compile: `javac ConstructorOverloading.java`
2. Execute: `java -cp . ConstructorOverloading`

## Result
The program successfully demonstrates constructor overloading by creating three Student objects using different constructors.
