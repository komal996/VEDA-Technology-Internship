# Task 4: Student Management System

A simple Java-based Student Management System developed as part of my VEDA Technology internship.

## Features

- Add student
- View student details
- Update student details
- Delete student
- Search student
- Menu-driven console application
- Uses Java classes and ArrayList

## Technologies Used

- Java
- JDK
- VS Code
- Command Line

## How to Run

Compile the program:

javac StudentManagementSystem.java
