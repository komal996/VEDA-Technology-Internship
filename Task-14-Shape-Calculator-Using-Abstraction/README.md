# Task 14 – Shape Calculator Using Abstraction

## Java Development Internship – VEDA Technology

### Project Overview
This Java project demonstrates **abstraction** in Object-Oriented Programming (OOP) through a shape calculator. It uses a common abstract shape definition and shape-specific implementations to calculate geometric measurements.

### Objectives
- Understand abstract classes and abstract methods in Java.
- Apply inheritance and method overriding.
- Practice polymorphism through a shape-calculation example.
- Write organized, reusable Java code.

### Concepts Used
- Abstraction
- Inheritance
- Method overriding
- Runtime polymorphism
- Classes and objects

### Technologies
- **Language:** Java
- **IDE:** Visual Studio Code
- **JDK:** Java Development Kit

### Project Folder
`Task-14-Shape-Calculator-Using-Abstraction/`

### How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal in that folder.
3. List Java files to identify the file containing `public static void main(String[] args)`:
   ```powershell
   dir *.java
   ```
4. Compile the Java source files:
   ```powershell
   javac -d . *.java
   ```
5. Run the class containing the `main` method:
   ```powershell
   java -cp . MainClassName
   ```
   Replace `MainClassName` with the actual class name (without `.java`).

### Expected Functionality
The program demonstrates how different shape classes can provide their own implementations of a shared calculation method. The exact supported shapes and calculations depend on the Java source code in this folder.
