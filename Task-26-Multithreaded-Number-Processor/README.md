
# Task 26 - Multithreaded Number Processor

## VEDA Technology Internship

### Objective
Understand Java multithreading and concurrent execution.

### Description
This Java program calculates the sum of numbers using
single-threaded and multithreaded approaches.

It compares their execution times and verifies results.

### Technologies Used
- Java
- Java Threads
- VS Code
- PowerShell

### Features
- Single-threaded number processing
- Multithreaded number processing
- Independent number ranges
- Execution time measurement
- Performance comparison
- Thread-safe result calculation

### Concepts Used
- Thread class
- start() method
- join() method
- run() method
- System.nanoTime()
- Thread safety

### How to Run

Compile:
javac -d . MultithreadedNumberProcessor.java

Execute:
java -cp . MultithreadedNumberProcessor

### Learning Outcomes
- Understanding multithreading in Java
- Dividing tasks between multiple threads
- Comparing program execution times
- Avoiding shared mutable state
- Understanding concurrency

### Conclusion
Successfully implemented single-threaded and
multithreaded numerical processing in Java.
