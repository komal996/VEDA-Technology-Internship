# Task 30 – Service and Program Management System

## Project Overview
The Service and Program Management System is a Java-based application designed to manage services and programs efficiently. It helps organize service-related information and perform management operations.

## Objectives
- Understand Java programming concepts.
- Develop a menu-driven management system.
- Organize and manage service and program information.
- Improve problem-solving and programming skills.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- VS Code / IntelliJ IDEA
- Command Prompt / PowerShell

## Project Structure
```text
Task-30-Service-and-Program-Management-System/
│
├── ServiceAndProgramManagementSystem.java
└── README.md
```

## How to Compile and Run

Compile:
```bash
javac -d . ServiceAndProgramManagementSystem.java
```

Run:
```bash
java -cp . ServiceAndProgramManagementSystem
```

## Features
- Service and program management.
- Organized information handling.
- Menu-driven operations.
- User-friendly console interface.

## Learning Outcomes
- Improved Java programming skills.
- Better understanding of application development.
- Practical experience with program management concepts.
