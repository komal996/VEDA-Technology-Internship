# Task 9: Simple Banking Account Class

## Description

A simple Java console application that simulates basic banking operations using object-oriented programming.

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* Validate transactions

## Technologies Used

* Java
* Visual Studio Code

## Concepts Used

Classes, objects, constructors, encapsulation, and methods.

## How to Run

```bash
javac BankAccount.java
java -cp . BankAccount
```

## Learning Outcome

Learned Java OOP concepts and how to implement basic banking operations.
